# User Guides

Welcome to the Cetmix Tower User Guides. This section provides comprehensive documentation for end users working with Cetmix Tower on a daily basis.

## Who Should Use These Guides

These guides are designed for:

- **End Users**: Staff members who use Cetmix Tower to manage servers and execute commands
- **Operations Teams**: Team members responsible for day-to-day server operations
- **DevOps Engineers**: Engineers using Tower for infrastructure management
- **System Operators**: Personnel performing routine server maintenance tasks

**Not sure if this is for you?**
- If you're looking to install or configure Cetmix Tower, see [Getting Started](../02-getting-started/README.md)
- If you're a developer looking for technical documentation, see [Technical Guides](../07-technical-guides/README.md)
- If you need module reference documentation, see [Module References](../05-module-references/README.md)

## Guide Organization

The user guides are organized by task complexity, from basic navigation to advanced operations:

### 1. [Navigation](./01-navigation.md)
Learn how to navigate the Cetmix Tower interface, understand the menu structure, and use different view types.

**Topics covered:**
- Tower interface overview
- Main menu structure (Servers, Commands, Flight Plans, Files, Variables)
- View types (list, kanban, form, calendar)
- Search and filtering capabilities
- User preferences and customization

**Recommended for:** All new users starting with Cetmix Tower

---

### 2. [Basic Operations](./02-basic-operations.md)
Master the fundamental operations you'll perform daily in Cetmix Tower.

**Topics covered:**
- Creating records (servers, commands, flight plans)
- Editing and updating records
- Deleting and archiving records
- Using filters and groups
- Exporting data
- Working with common UI elements (buttons, actions, wizards)

**Recommended for:** Users who need to manage Tower resources

---

### 3. [Common Tasks](./03-common-tasks.md)
Step-by-step guides for the most common daily operations.

**Topics covered:**
- Running commands on servers
- Checking command execution logs
- Managing files on servers
- Viewing server status
- Using shortcuts for quick access
- Understanding notifications and alerts

**Recommended for:** Daily Tower users performing routine operations

---

## Getting Help

If you can't find what you're looking for in the user guides:

1. **Search the documentation**: Use the search function to find specific topics
2. **Check Feature Guides**: See [Feature Guides](../04-feature-guides/README.md) for detailed feature documentation
3. **Review Module References**: Consult [Module References](../05-module-references/README.md) for technical details
4. **Report Issues**: If you encounter bugs, see [Issues & Bugs](../12-issues-bugs/README.md)

## Documentation Conventions

Throughout these guides, we use the following conventions:

- **Bold text**: UI elements (buttons, menu items, field names)
- `Code text`: References, commands, or technical values
- 📝 **Note**: Important information to remember
- ⚠️ **Warning**: Critical information or potential issues
- 💡 **Tip**: Helpful hints and best practices
