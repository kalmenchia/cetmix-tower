## Issue Tracking

Cetmix Tower issues are tracked on GitHub:
- **Repository**: [https://github.com/cetmix/cetmix-tower](https://github.com/cetmix/cetmix-tower)
- **Issues**: [https://github.com/cetmix/cetmix-tower/issues](https://github.com/cetmix/cetmix-tower/issues)

## Issue Categories

Issues are organized by:
- **Severity**: Critical, High, Medium, Low
- **Type**: Bug, Feature Request, Enhancement, Question
- **Module**: Which Tower module is affected
- **Status**: Open, In Progress, Resolved, Closed

## Getting Help

Before reporting an issue:

1. **Check Documentation**: Review relevant feature guides
2. **Search Existing Issues**: Your issue may already be reported
3. **Check Logs**: Review command/plan logs for error details
4. **Test in Development**: Try to reproduce in a test environment
